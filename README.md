# React 簽到系統

這是一個簡單的簽到小工具，使用者最多可以新增5個標籤，在每個標籤中使用者可以打入自己的資訊來簽到，完成簽到後點下載CSV可以下載所有簽到者的資訊及簽到時間。

- 有系級、名字、學號、時間四個欄位
- 簽到資料會被暫存在瀏覽器中
- 可以將簽到資料下載成CSV檔案
- 可同時使用5個不同的標籤
